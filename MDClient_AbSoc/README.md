# MultiDraw Socket Client

## Description
A real-time client-server drawing application built using C# sockets, enabling multiple users to communicate and share drawing data over a network.

## Technologies Used
- C#
- .NET
- Sockets
- Object-Oriented Programming

## Features
- Real-time data transmission between clients
- Custom socket-based communication layer (AbSoc)
- Interactive drawing synchronization
- Modular and reusable architecture

## Notes
This project demonstrates networking, threading, and object-oriented design concepts in C#.
